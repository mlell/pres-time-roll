# Example Presentations

This folder contains example remark.js presentations that you can use with Classtimer.

## How to Use

1. Open `classtimer.html` in your browser
2. Drag and drop any `.md` file from this folder onto the drop zone
3. Press `C` to open the presentation in a new window
4. Press `P` to open in presenter mode (via new window)

## Files

- `sample-presentation.md` - A basic introduction to remark.js with various slide types

## Keyboard Shortcuts (in new window)

- `C` - Clone the display (for presenter mode)
- `P` - Switch to presenter mode
- `H` - Open help menu
- `Space`, `Enter`, `→`, `PgDn` - Next slide
- `Backspace`, `←`, `PgUp` - Previous slide
